# สรุปโปรเจกต์: เว็บรวมร้านเสื้อผ้ามือสองคัดพิเศษ

> ชื่อชั่วคราว: Curated Hub (ยังไม่มีชื่อแบรนด์จริง)

## ไอเดียในประโยคเดียว

เว็บที่รวมร้านเสื้อผ้ามือสองที่มีสไตล์จากทั่วประเทศไว้ที่เดียว ให้คนต่างจังหวัดช้อปร้านดังในกรุงเทพได้ และให้ร้านเล็กที่มีรสนิยมได้ลูกค้านอกเมืองตัวเอง

## ปัญหาที่แก้

- **ผู้ซื้อ:** เสื้อผ้ามือสองต้องคุ้ยเยอะกว่าจะเจอตัวที่ชอบ และไม่กล้าโอนเงินให้ร้านที่ไม่รู้จัก เพราะกลัวของปลอมหรือไม่ตรงปก
- **ร้าน:** ร้านมือสองเจ๋งๆ ส่วนใหญ่ขายได้แค่ลูกค้าในเมืองตัวเองหรือคนที่ตาม IG อยู่แล้ว

## สิ่งที่ทำให้ต่างจากที่อื่น

- **คัดที่ร้าน ไม่ใช่คัดทีละชิ้น:** รับเฉพาะร้านที่มีสไตล์ชัด ไม่ใช่เสื้อยืดตลาดนัดทั่วไป
- **มาตรฐานรูปเดียวกันทั้งเว็บ:** ทุกชิ้นต้องมีรูปหน้า หลัง ป้ายแบรนด์ และรูปตำหนิ (ถ้ามี) ให้เช็กสภาพและความแท้ได้
- **เว็บถือเงินไว้ให้:** จ่ายผ่าน QR พร้อมเพย์ เงินถึงร้านเมื่อผู้ซื้อยืนยันว่าได้ของแล้ว
- **ต่อราคาได้:** ยื่นข้อเสนอ ร้านรับ ปฏิเสธ หรือโต้กลับได้
- **ค้นหาด้วยรูป (อนาคต):** แคปลุคเจ๋งๆ จาก TikTok แล้วหาของที่คล้ายกันในเว็บ
- **แต่ละร้านมีหน้าร้านของตัวเอง** เช่น `ชื่อเว็บ.com/tuekdaeng`

## กลุ่มลูกค้า

คนไทยวัยรุ่นถึงวัยทำงานที่ตามแฟชั่นผ่าน TikTok และ IG เข้าเว็บจากมือถือเป็นหลัก

สไตล์หลักในเว็บ:
- สตรีทแวร์
- วินเทจ
- แบรนด์เนม
- Y2K
- เกาหลี-ญี่ปุ่น
- เวิร์กแวร์

## ฟีลของแบรนด์

- เรียบ ดูจริงจังน่าเชื่อถือ แต่ไม่น่าเบื่อ
- สตรีท แฟชั่นจ๋า
- สนุก น่าเล่น
- เว็บอ้างอิงด้านโครงสร้าง: carnivalbkk.com (ยืมความเรียบและการจัดหมวด ไม่ลอกหน้าตา)

## โมเดลรายได้

ค่าคอมมิชชันต่อออเดอร์ ช่วงเปิดตัวมีโปร 0% เพื่อดึงร้านเข้ามา

## โจทย์สำหรับการตั้งชื่อ

ชื่อที่ดีควร:
- **สั้น จำง่าย พิมพ์ง่ายบนมือถือ** ลูกค้าจะพิมพ์ค้นหาหรือบอกต่อเพื่อน
- **อ่านได้ทั้งไทยและอังกฤษ** หรือมีชื่อไทยกับชื่ออังกฤษที่ไปด้วยกัน
- **ใช้เป็นโดเมนและชื่อ IG/TikTok ได้** ควรเช็กว่ายังว่างอยู่ (.com หรือ .co / .shop)
- **ไม่ผูกกับกรุงเทพ** เพราะรวมร้านทั่วประเทศ
- **สื่อถึงการคัด / ของมือสองที่มีของ / ความสตรีท** อย่างน้อยหนึ่งอย่าง
- **ไม่ฟังดูเหมือนตลาดนัดหรือของถูก** เพราะจุดขายคือรสนิยม
- **ไม่ชนกับแบรนด์ที่มีอยู่แล้ว** โดยเฉพาะร้านเสื้อผ้าในไทย

ทิศทางที่ลองคิดได้:
- คำที่เกี่ยวกับการคัด การล่า การขุดของ
- คำที่เกี่ยวกับตู้เสื้อผ้า ราวแขวน ชีวิตที่สองของเสื้อผ้า
- คำสแลงหรือคำที่คนสายสตรีทใช้กัน
- คำผสมไทย-อังกฤษที่ออกเสียงสนุก
